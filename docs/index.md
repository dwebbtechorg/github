# Welcome

This is an **example MkDocs site** built with the [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) theme.

It is packaged as a Docker container and deployed to a self-hosted runner using GitHub Actions.

## What's inside

- A handful of example documentation pages
- A `Dockerfile` that builds and serves the site
- A GitHub Actions workflow that runs on a self-hosted runner

!!! tip "Quick start"
    Head over to [Getting Started](getting-started.md) to build and run the site locally.
