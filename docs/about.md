# About

This repository is an example of packaging an [MkDocs](https://www.mkdocs.org/)
documentation site as a Docker container and deploying it through GitHub
Actions on a self-hosted runner.

## Goals

- Demonstrate a minimal, reproducible docs build
- Show a container-based deployment using host networking
- Provide a CI/CD workflow that targets a self-hosted runner
